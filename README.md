# Boarding House Management

A small Flask-based boarding house management dashboard for tracking rooms, residents, payments, and expenses.

## Features

- Dashboard summary cards
- Room management
- Tenant/resident management
- Rent payment tracking
- Expense tracking

## Setup

```bash
python -m pip install -r requirements.txt
python app.py
```

Then open http://127.0.0.1:5000/

## Testing

```bash
python -m pytest -q
```
